# Comments & bios

Comments on a published lesson and the bio on your profile can both have a
little formatting and links. They can't hold pictures, video or other media.

## Writing a comment or bio

The box you type in has a small toolbar:

| Button                                          | What it does                                            |
| ----------------------------------------------- | ------------------------------------------------------- |
| **Bold**, **Italic**, **Underline**             | Formats the selected words.                             |
| **Strikethrough**, **Code**                     | Crosses words out, or shows them as code.               |
| **Bulleted list**, **Numbered list**, **Quote** | Turns the paragraph into a list or a quote.             |
| **Link**                                        | Adds a link to the selected words.                      |
| **Remove formatting**                           | Clears formatting, lists and quotes from the selection. |

Headings and tables aren't offered: a comment is a paragraph or two, not a
document.

Links can go to web pages (`http://` or `https://`) or email addresses
(`mailto:`). Anything else isn't made into a link. Typing a web address on its
own turns it into a link as you go. Links always open in a new tab.

Pasting or dragging a picture or file into the box does nothing, on purpose.

## Length

A comment can be up to 2,000 characters and a bio up to 500. Only the words
you write count, not the formatting, and the counter under the box shows how
many you've used.

## Editing a comment

You can edit your own comment after posting it: choose **Edit** on the
comment, make your changes and press **Save changes**. Once edited, the comment shows **edited** next to it, so people who
already read or replied to it can tell it changed. The same rules apply to an
edit as to a new comment.

Nobody else can edit your comment, not even a moderator. Moderators can only
delete a comment (see [Moderation](./moderation.md)).

To change your bio, edit it again from your profile or from Settings (see
[Profiles](./profiles.md)).

## Comments and bios from before formatting

Older comments and bios, written before formatting was added, are shown just
as they were written, line breaks included.

Lesson text has formatting too, but it works differently: see
[Formatting, footnotes & sources](./formatting-and-footnotes.md).

For how this works, see the [developer notes](../developers/web-app/rich-text.md).
